# Eski tasarım arşivi

Bu klasördeki belgeler, motorun **önceki** mimarisine aittir (fuzzy family matching, çok alanlı
PREFILL binding'leri, artımlı/incremental state, `role`/`widget`/`parameters`/`breaksEpisode`
alanları dahil). `AWE_MVP_TASARIMI_BAGIMSIZ_INCELEME.md` spesifikasyonuna göre yapılan yeniden
tasarımla birlikte bu belgeler **artık uygulanmaz** — yalnızca tarihsel referans ve o
kararların neden alındığına dair gerekçe kaynağı olarak saklanır.

Güncel mimari için bkz. [`docs/architecture.md`](../architecture.md) ve
[`docs/engine-decisions.md`](../engine-decisions.md).

- `AWE_MASTER_SPEC.md` — motorun ilk (önceki) sürümünün inşa edildiği ~33 bölümlük orijinal
  spesifikasyon.
- `IMPLEMENTATION_PLAN.md` — o spesifikasyonun açık bıraktığı noktalarda hangi somut tasarım
  kararının verildiğinin kaydı (fuzzy matching formülleri, cadence-relative liveness, IDF
  ağırlıklandırma vb.). Bu kararların hiçbiri güncel motorda yoktur.
